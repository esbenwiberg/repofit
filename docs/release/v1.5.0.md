# repofit v1.5.0

Additive CLI and evidence release, coordinated with corpus-default 2.3.0.

## Changes

- Add opt-in `repofit analyze` for scoped lexical policies, suppression/comment/example risks, recurring implementation candidates and declared verification capabilities. Initial adapters cover TypeScript/JavaScript and C#; unsupported/compiler/framework semantics remain unknown.
- Persist bounded source facts under `.repofit/cache/`. Warm scans reuse unchanged file contents using metadata; `--rehash` forces byte reads. Coverage, omitted facts and cost limits are explicit.
- Keep structural differences advisory. Optional `--judge` uses bounded, cached packets and validated related locations; no majority convention becomes a correctness rule.
- Add explicit `--experiment` valid/invalid enforcement checks in independent snapshots. Preserve input bytes/modes, check source/fixture integrity, and terminate descendant processes on timeout. Commands are trusted caller code; snapshots are not an OS sandbox.
- Read neutral `.agent/verification.json` feature/control declarations, including `{port}` URL templates, without executing them or inferring successful verification.
- Retain already-executed command attempts, including warm-ups, failures/timeouts, command/cwd, elapsed time and bounded diagnostics, in JSON, human and HTML reports. First observed execution does not imply a clean cold environment.
- Extend the SDK with optional execution evidence, lazy analysis evidence and structured related-location judge findings. Existing optional-field omissions remain supported.

Ordinary default checks invoke no new repository commands or model calls. No existing probe IDs, bands or baseline scores change. See [advisory analysis](../advisory-analysis.md) for usage, budgets and limitations.

## Upgrading

```sh
npm install --save-dev @esbenwiberg/repofit@1.5.0 @esbenwiberg/corpus-default@2.3.0
npx repofit --version
npx repofit analyze
```

Projects that pin the default corpus in `repofit.config.json` should use exact version `2.3.0`. Existing baselines are retained; review the reported corpus-version drift before deliberately accepting a replacement. This release does not automatically accept a baseline.
