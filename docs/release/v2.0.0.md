# corpus-default v2.0.0

Agent-instructions release. The `agent.*` family is rebuilt around a field
study of 55 open-source repositories ([research](../research/) and the
[corpus v2 design](../design/corpus-v2-agent-instructions.md)): a root that
is thin and routes, nested guidance only where priorities differ, skills with
one source and a trigger line, and references that resolve. Two probe ids are
retired and two reasoned rubrics change meaning, which is why this is a major.
Requires `@esbenwiberg/repofit` 1.3.0.

## Changes

- **Retired ids.** `agent.guidance-substance` is replaced by
  `agent.root-budget`; `agent.guidance-nested` by
  `agent.nested-guidance-lean`. A config that disables, waives or includes a
  retired id now gets a warning naming the replacement.
- **New deterministic `agent.*` probes.** `agent.root-budget` (bands at
  6/12/24/48 KB, waivable), `agent.root-routes`, `agent.nested-guidance-lean`,
  `agent.harness-adapters-thin`, `agent.skills-single-source`,
  `agent.skill-descriptions-trigger`, `agent.references-resolve`,
  `agent.commands-resolve`, `agent.shared-files-portable` and
  `agent.local-settings-not-committed` (Safety, weight 0.3). They return
  `na` for repositories without the relevant files, so a repository with no
  skills or nested guidance is mostly unaffected.
- **Opt-in `agent.skill-evals-present`.** Runs only when named in
  `gate.include` or `--include`.
- **Reasoned rubrics rewritten.** `agent.guidance-quality` and
  `agent.guidance-fresh` are version 2.0.0: they score only what reading can
  tell (instructions versus documentation, boundaries, stale claims against
  the manifest and tracked counts) and leave size, paths and commands to the
  deterministic probes. `agent.guidance-aligned` skips pointer and link
  adapters. `agent.skills-quality` samples skills from any `skills` directory
  and no longer samples `.claude/commands` or `prompts/agents`.
- **`tests.mutation-configured`.** A static presence probe for a mutation
  testing configuration in the Feedback dimension.
- **Evidence.** Probes use the engine's extended `agent_config` evidence:
  instruction files with depth, size and link information, skills with
  frontmatter, and harness config files.

## Upgrading

```bash
npm install --save-dev @esbenwiberg/repofit@1.3.0 @esbenwiberg/corpus-default@2.0.0
```

Then bump the corpus pin in `repofit.config.json` to `2.0.0`, replace any
retired ids the config names, and re-accept the baseline with
`repofit check --accept`. Expect the Context score to move: repositories with
copied guidance, blind references or undefined commands drop, and that is the
signal.
