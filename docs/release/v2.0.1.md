# corpus-default v2.0.1

False-positive patch release. Running 2.0.0 against a well-maintained
TypeScript application scored several real practices as absent: a fetch of a
reserved host, an architecture check and a mutation script of the
repository's own, a contributing guide under `docs/`, and design previews
counted as large files. Five probes get a patch bump; no id, band or
dimension changes. Requires `@esbenwiberg/repofit` 1.3.0.

## Changes

- **`tests.deterministic` 1.0.1.** A `fetch` or `axios` call to a reserved
  host (`localhost`, `127.x`, `[::1]`, or a `.localhost`, `.test`,
  `.example` or `.invalid` TLD) is a stub, not a network call, and is no
  longer flagged. A bare `fetch(...)` in a file that binds its own `fetch`
  (`const { fetch } = setup()`, a `fetch` parameter) is skipped too; an
  imported `fetch` and member calls such as `client.fetch(...)` stay flagged.
- **`arch.fitness-tests-configured` 1.0.1.** A package script whose name
  carries an `arch`, `architecture` or `boundaries` token, or whose command
  invokes an architecture or boundary check (`check-architecture.mjs`,
  `depcruise`, `madge`, `lint-imports`), now counts alongside the known
  tools. The probe takes the script at its word; a script that says `arch`
  and checks nothing is the repository's claim to keep honest.
- **`tests.mutation-configured` 1.0.1.** A package script whose name carries
  a `mutation`, `mutants`, `stryker` or `mutmut` token, or whose command
  invokes a mutation tool, now counts: a curated set of reviewable mutation
  probes is a configured artefact that edits code and expects a failure.
- **`docs.contributing-present` 1.0.1.** A contributing or contributor guide
  under `docs/` or `.github/` (`docs/contributor-workflow.md`,
  `.github/CONTRIBUTING.md`) satisfies the probe as well as the root file.
  A `contributors` roster does not. The probe now also reads `size_stats`.
- **`size.large-files` 1.0.1.** Binary files (images, fonts, media,
  archives, compiled artefacts, matched by extension) are excluded from the
  count: a design preview or screenshot is storage, not agent context. The
  rationale says so.

Not changed: `hooks.gates-lint-test-build` still reads only the hook and
the `.sh` siblings it references. A hook that `exec`s an interpreter script
(`python3 scripts/checks.py staged`) is not followed; see the pull request
for why that stays deterministic-unfriendly.

## Upgrading

```bash
npm install --save-dev @esbenwiberg/corpus-default@2.0.1
```

Then bump the corpus pin in `repofit.config.json` to `2.0.1` and re-accept
the baseline with `repofit check --accept` if any of the five probes move.
