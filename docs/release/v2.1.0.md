# corpus-default v2.1.0

Three probes from the field-study items the 2.0 plan left open
([esbenwiberg/repofit#18](https://github.com/esbenwiberg/repofit/issues/18),
[#19](https://github.com/esbenwiberg/repofit/issues/19),
[#20](https://github.com/esbenwiberg/repofit/issues/20)). No id, band or
dimension changes to existing probes; `generated.code-marked` is refactored
onto a shared helper with identical behaviour. Requires
`@esbenwiberg/repofit` 1.3.0. Design: `docs/design/corpus-v2-agent-instructions.md`
§5.16 to §5.18.

## New probes

- **`agent.nested-guides-routed` 1.0.0** (context 1, static). Lists the
  nested `AGENTS.md`, `CLAUDE.md` or `GEMINI.md` directories the canonical
  root does not name, by file path, by directory, or by a backticked or
  linked scope glob such as `packages/*/AGENTS.md`. Bands `0 → 100`,
  `1 → 70`, `≤ 3 → 40`, else `0`. `na` without nested guides or without a
  root. Issue #20 proposed this as a facet of `agent.root-routes`; it is a
  separate inventory probe so each unreachable guide is named and can be
  waived by path. Precedence prose stays in `guidance-quality`.
- **`agent.generated-paths-protected` 1.0.0** (safety 0.3, static). Groups
  every tracked generated file (`linguist-generated`, or recognisable by
  path or header, lockfiles excluded) by directory and reports the
  families no write-tool deny (`Edit`, `Write`, `MultiEdit`,
  `NotebookEdit`) in a tracked `.claude/settings.json` covers. Globs are
  resolved gitignore-style relative to the settings file's project
  directory. `settings.local.json` never counts. Bands `0 → 100`,
  `≤ 2 → 50`, else `0`. `na` without generated files or without a shared
  `.claude/settings.json`.
- **`agent.untrusted-content-framed` 1.0.0** (safety 0.5, reasoned). Judges
  whether the guidance frames issue, pull-request, comment, page and tool
  output as data rather than instructions, names this repository's own
  surfaces, and says what to do when such content tries to steer the
  agent. A deterministic prefilter finds the surfaces first (review or
  triage skills, `gh issue|pr` reads, workflows reading event bodies or
  running a coding-agent action) and returns `na` when there are none.
  Reasoned tier: excluded unless `gate.include` lists it.

## Shared helpers

`probes/_shared/generated-files.ts` (generated-file detection, shared by
`generated.code-marked` and `agent.generated-paths-protected`) and
`probes/_shared/glob.ts` (gitignore-style matcher for harness permission
globs and root scope globs).

## Upgrading

```bash
npm install --save-dev @esbenwiberg/corpus-default@2.1.0
```

Then bump the corpus pin in `repofit.config.json` to `2.1.0` and re-accept
the baseline with `repofit check --accept`. Two new probes score on most
repositories with nested guides or generated code; a root that names none
of its nested guides drops Context, which is the signal.
