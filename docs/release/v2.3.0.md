# corpus-default v2.3.0

Coordinated with repofit 1.5.0, required for lazy analysis evidence.

## Changes

- Add opt-in `arch.declared-policy-assessment`, which assesses explicit repository lexical restrictions. It is N/A without a valid policy and is excluded from default checks. Unjudged structural differences and undeclared app controls do not receive fitness deductions.
- Correct `safety.dangerous-script-flags` remediation: assess actual scope, permissions and failure behavior, and use explicit justified waivers when appropriate. A code comment never automatically exempts a risky command; useful comments and supported suppressions remain valid.
- Clarify `arch.fitness-tests-configured`: configured architecture tools are not proof they execute or reject invalid input. Explicit `repofit analyze --experiment` records that evidence separately.

Existing probe IDs, scoring bands and dimension weights are unchanged. No baseline is automatically accepted.

## Upgrading

```sh
npm install --save-dev @esbenwiberg/repofit@1.5.0 @esbenwiberg/corpus-default@2.3.0
```

Update the corpus pin in `repofit.config.json` to exact version `2.3.0`. The new policy probe runs only when explicitly selected with `repofit check --probe arch.declared-policy-assessment`.
